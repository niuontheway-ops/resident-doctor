# 《住院总之夜》游戏设计文档

> 规培教学 Web App 的**随机病例夜班冒险（Roguelike）**模块 ｜ v0.1 设计稿，待医学教师审核
> 适用：内科／急诊／全科专业基地规培医师（第 2—3 年为主）
>
> **边界声明**：医学内容依据人民卫生出版社《内科学》（第 10 版）与《诊断学》（第 10 版）的通行教学表述编写，**不引用原文、不标页码、不虚构指南结论**。凡涉及药物剂量、操作规格、评分阈值、时间窗者均标注「需要临床教师复核」，上线前须逐条确认并以本院现行规范为准。全部病例为教学虚构数据，**不得作为临床决策依据**。
>
> **严肃性声明**：本模块涉及患者恶化与死亡的表达，一切文案、动效、结算规则须遵循第 12 章准则。任何将患者伤害娱乐化的实现（庆祝反馈、连击计数、死亡数排行）一律视为**缺陷**，必须修正。

## 1. 游戏定位与学习目标

规培中有一类能力长期缺乏训练场：**在信息不完整、时间不够、人手不足、且同时有多个患者时做出可辩护的决策**。题库把临床削减成「一个患者、一份完整资料、一个正确答案」；真实夜班恰恰相反——资料残缺、时间竞争、诊断常在处理之后才明确，而最关键的一步往往不是「治什么」，而是「什么时候承认自己搞不定，把上级叫起来」。

本作把一夜做成一次 Roguelike 跑局：地图与病例随机生成，资源不可再生（时间、精力、床位、上级注意力），失败不回档，但每次失败都产出结构化学习报告。单局 25—40 分钟，5 个时段层 + 交班层，8—14 个节点（含 3—5 个完整病例）；手机竖屏优先，纯前端离线可用。

### 1.1 三项核心胜任力映射

| 胜任力 | 临床形态 | 承载机制 | 结算度量 |
|---|---|---|---|
| **不确定性下的决策** | 诊断未明即需处理；能「先稳定后诊断」 | 信息分「已知/待查/不可得」三态；部分检查永远拿不到；须在缺口下选择四类动作 | 关键处理是否早于确诊；是否滥查；假设是否随证据修正 |
| **资源分配** | 时间、监护床、护理人力、血制品、影像通道均稀缺，给了 A 就没给 B | 三维消耗全局共享；层间不完全恢复；同层多节点只能选部分 | 高危是否优先；稀缺资源是否给了最需要者；是否因追低危线索而漏高危 |
| **寻求帮助的时机** | 既不能事事请示，也不能硬撑到不可逆 | 上级呼叫有次数上限与响应延迟；求助过早付小成本，过晚触发不可逆分支 | 首次求助时点 vs 建议求助窗口；红线事件前是否完成呼叫 |

### 1.2 学习目标

**知识（K）**：急性呼吸困难的鉴别框架（急性左心衰、慢阻肺急性加重、哮喘急性发作、肺栓塞、气胸）；胸痛的致命病因优先排除；意识障碍的可逆病因先筛（低血糖、缺氧、二氧化碳蓄积、电解质、肝性脑病、药物、颅内、感染）。**张力性气胸属临床诊断**，血流动力学不稳定时不等影像。脓毒症的概念框架（感染 + 器官功能障碍）与初始处置逻辑：留取病原学标本、尽早经验性抗感染、液体复苏与反应性评估、血管活性药、感染源控制（**时限、液体量、血压目标、药物选择需要临床教师复核**）。上消化道出血的病因分层与「容量评估优先于内镜时机」。

**能力（S）**：① 分诊排序（按气道—呼吸—循环—意识与时间敏感度）；② 有目的的观察（说得出观察什么、多久复评、什么阈值升级）；③ 结构化求助表达（现况—背景—评估—请求）；④ 资源取舍并说明理由；⑤ 无损交班。

**态度（A）**：承认能力边界不是失败；家属沟通是医疗行为而非额外麻烦；对恶化与死亡保持严肃；复盘针对决策与系统，不针对人格。

**反目标**：不做等级碾压（成长不提高成功率）；不做「猜诊断得分」；不做超现实道具；不做患者伤害的娱乐化表达；不做剂量执行器（药物只到「类别与时机」，避免被误用为临床工具）。

## 2. 地图结构

有向分层图，每层 2—4 个可选节点，时间预算只允许完成一部分。未选节点不消失，而是**转入后台队列**，可能在后续层以恶化形态回归——**你没做的事不会自动消失**，这是本作最重要的结构性教学点。层不可回退。

| 层 | 时段 | 主题 | 可达/需完成 | 场景 | 核心考点 |
|---|---|---|---|---|---|
| L0 | 17:30 | 交班（固定） | 1/1 | 接班、患者清单与风险预警 | 从交班中识别「今夜最可能出事的 3 个人」 |
| L1 | 18:00—21:00 | 常规病房 | 3/2 | 呼吸／心内／消化病区：临时医嘱、发热、疼痛、家属询问 | 区分「可延后事务」与「早期恶化信号」 |
| L2 | 21:00—23:30 | 急诊会诊 | 3/2 | 抢救室、留观区、急诊内科会诊 | 未分化主诉的快速危险度分层 |
| R1 | 23:30 | **休息点** | 可跳过 | 值班室：进食、查手册、整理待办、向上级汇报 | 自我状态管理 |
| L3 | 00:00—02:30 | 深夜恶化 | 4/2 | 病房夜间变化 + 检查通道受限 | 多线程管理；检查不可得时靠床旁手段 |
| L4 | 02:30—04:30 | **危重病例层** | 1/1 | 从 Boss 池按本局历史抽取 | 综合处置与求助时机 |
| R2 | 04:30 | 休息点 | 可跳过 | 整理病历、清点残留 | 收尾与风险清点 |
| L5 | 05:00—08:00 | 晨交班结算 | 1/1 | 结构化交接 + 晨间家属沟通 | 信息交接完整性 |

**节点类型**：完整病例（3—6 决策回合，20—60 min）；事务（补签医嘱、输液反应、镇痛/失眠请求，约 15% 内藏早期恶化信号如反复要求坐起）；会诊（只给二手信息，训练「不亲眼看就不下结论」）；沟通（与 `08-有温度的问诊室` 共用评分维度）；休息点；危重病例（第 8 章）；回归节点（后台队列的恶化形态，不可跳过）。

**分支预览刻意不完整**：只给「年龄 + 性别 + 一句主诉 + 预计耗时」，**不给生命体征**（模拟护士口头汇报粒度），玩家须凭主诉危险度启发式排序。想要生命体征需花 5 min 打电话问护士——系统**不惩罚**，并在结算记为正向行为。

```
L2 急诊会诊层（预算 150 min，只够 2 个）
[A] 抢救室 · 男 24 · 「打球后突然胸痛喘不上气」   30-50 min
[B] 留观区 · 女 71 · 「说不出话，喊不醒」        40-60 min
[C] 急诊内科 · 男 58 · 「拉黑便两天，头晕」      30-45 min
第 3 位由急诊值班医师暂时处理，你将在后续时段收到关于 TA 的消息。
```

**休息点是一个真实的两难**：完整休息（30 min，精力 +30，队列全部推进 1 恶化步）｜简短休息（10 min，+12，队列推进 0—1 步）｜查阅资料（15 min，+5，解锁 1 个病例的诊断要点）｜整理队列（20 min，−5，队列冻结一层）｜向上级非紧急汇报（10 min，−3，耗 0.5 次额度换取上级对 1 名高危患者预先知情，后续紧急呼叫响应减半）｜跳过（−8）。

**疲劳态（精力<30）**：随机隐藏 1 条已获得的关键信息（灰色「你似乎漏看了什么」，可花 5 min 取回）；取消选项默认高亮。**精力不影响任何医学结果概率**——只影响「你能否看见信息」，不影响「你处理得好不好」。

**终点是 L5 晨交班，不是「打赢危重病例」。** 即使 L4 结果不理想（包括患者死亡），跑局仍继续到晨交班——真实夜班不会因一个坏结果而结束，你还得值完班、还得交班。结算不给胜/败标签，给四张卡：患者结局摘要、决策路径回放、资源使用审计、学习报告。

## 3. 随机事件系统

**铁律：事件是约束生成器，不是伤害生成器。** 随机事件只改变「你能拿到什么信息、什么时候拿到、有多少手可用」，**不直接改变患者的病理生理**。恶化只有两个来源：疾病自然进程（由病例时间轴定义）、玩家决策的延迟或错误。这避免「运气杀人」，也保证复盘时因果链可追。

| 事件 | 医学含义 | 权重与调制 | 表现 | 处理方式与教学点 |
|---|---|---|---|---|
| **E1 检查延迟／不可得** | 夜间通道受限：仪器保养、技师单人值守、转运需监护陪同、增强 CT 需评估肾功能与过敏史 | 18%；L3 ×1.8；非急诊项目 ×1.5；同层已请求≥3 项 ×1.4 | 结果延迟（20→60 min）／需转运（+15 min 且占护理人力）／当夜不可得 | 用床旁替代（超声、血气、心电图、体检复评）；标记晨间待查；向上级说明缺失下的方案。**检查是手段不是目的：张力性气胸不等胸片，心电图须床旁快速完成** |
| **E2 床位紧张／资源竞争** | 监护床、抢救室位、ICU 床、血制品均有限 | 15%；已用监护床≥2 ×2.0；L2/L4 ×1.5 | 仅剩 1 张监护床而有 2 名候选／ICU 无床／配血需 40 min | 显式排序并选理由标签（时间敏感度/可逆性/监护必要性）；无床时给替代方案（专人守护 + 缩短复评 + 升级阈值）。**分配需可辩护；「没有床」不等于「不能治」** |
| **E3 信息缺失** | 外院病历未带、患者失语、家属不在、用药记不清、过敏史不明 | 22%（最高）；L2 ×1.6；意识障碍病例强制 100% | 「不可得」灰锁字段／二手信息并标注可靠性／两条互相矛盾的信息 | 调阅本院病历、联系家属、查随身药盒、体检线索（手术疤痕、胰岛素注射点、透析通路）；写明「假设 + 风险」。**体检可替代部分病史；「不明」应写进病历而非默认为「无」** |
| **E4 多患者同时变化** | 夜班的本质困难 | 12%；L3 ×2.2；队列≥3 项 ×1.8；Boss-3 为专门形态 | 同时弹出 2—3 条护士呼叫，各一句话，开始计时 | 30 秒内排序；委派护士做具体动作（给氧、抬高床头、测血糖、上监护、开静脉、备抢救车）。**委派是核心能力：清晰、具体、可执行、有回报点；排序依据是气道/呼吸/循环/意识的即刻威胁而非呼叫先后** |
| **E5 设备故障／流程障碍** | 导联脱落伪报警、探头读数不可信、心电图机缺纸、超声机被借走、转运延迟 | 10%；同设备用≥3 次后 ×1.6 | 伪异常数据（血氧 62% 但对答如常无窘迫）／设备不可用／转运延迟 | **数据与患者不符时先看患者**：复测、换探头、看波形、查脉搏灌注。**《诊断学》基本态度：体征优先于数字，波形优先于数值**；同时训练不因数字异常过度处置 |
| **E6 家属情绪** | 焦虑、恐惧、不信任、内疚、悲伤、愤怒——均源于信息不足与失控感 | 16%；恶化后 ×2.5；未及时告知超一层 ×2.0；死亡后 100% 不可跳过 | 反复追问／要求「用最好的药」／拒绝检查／对前班不满／要求转院／要求进抢救现场 | 承接情绪→澄清信息→说明下一步与时间点→给联系方式。**无「安抚成功率」骰子**，评价基于结构化沟通要素（**框架与本院知情同意流程需要临床教师复核**） |

**E6 强制约束**：家属情绪**不得**作为难度调味料或喜剧素材，不得出现「闹事家属」类刻板刻画。敷衍选项存在，但会在复盘中标记为沟通缺口并给出改写示例。

```js
function rollEvent(ctx) {
  const w = { E1:18, E2:15, E3:22, E4:12, E5:10, E6:16 }; // 余 7% 无事件
  for (const r of RULES) if (r.when(ctx)) w[r.event] *= r.factor;
  if (ctx.lastEvent) w[ctx.lastEvent] *= 0.25;            // 不连续重复
  for (const k in w) if (ctx.count[k] >= CAP[k]) w[k] = 0;
  if (ctx.justDied) { w.E4 = 0; w.E5 = 0; w.E6 = 100; }   // 哀伤场景不叠加忙乱
  return weightedPick(w);
}
```

单局上限 `CAP`：E1≤3、E2≤2、E3≤4、E4≤2、E5≤2、E6≤3，防止随机性把一局变成灾难拼盘。

## 4. 病例生成规则（核心章节）

### 4.1 问题与解法

随机组合是 Roguelike 的引擎，但医学病例不能随机拼装。把「20 岁男性」+「长期激素致骨质疏松」+「黑便」+「血肌酐 600」+「突发牙关紧闭」拼在一起，得到的不是稀有病例，是**教学负资产**——学员会习得错误的疾病模式。解法：**不做槽位级随机，做锚定式生成 + 约束求解 + 硬校验。**

```
Step 1 ANCHOR    先随机选定「疾病核心」core = 一个明确的病理生理诊断
                 core 自带：人群画像、时间轴、必须成立的体征集、禁止共存诊断集、
                            检查值域、进展树、criticalActions、建议求助窗口
Step 2 CONSTRAIN 由 core 推导五槽位「允许集」
                 S 主诉 ⊆ allowedComplaints；B 基础疾病 ⊆ allowedComorbidity（+年龄/性别）
                 T 诱因 ⊆ allowedTriggers（+时间轴）；F 检查 ⊆ findingRanges（+生理耦合）
                 E 突发变化 ⊆ progressionTree（+因果可达）
Step 3 FILL      在允许集内随机填充 ← 随机性唯一来源
                 随机维度：主诉措辞、共病组合、诱因细节、数值抖动、恶化时点、
                           信息可得性、家属在场情况
Step 4 VALIDATE  逐条跑 R/C/D 三组硬约束，任一失败→丢弃重掷；
                 连续 5 次失败→写日志并回退到教师手写的保底病例
```

**关键认识**：随机性被限制在「同一个正确疾病的不同表现形态」，而非「不同疾病的零件互换」。玩家感受到的多样性来自——同一个张力性气胸，可能是打球后的瘦高青年，也可能是慢阻肺基础上的继发性气胸；可能先以胸痛为主诉，也可能以「突然喘不上气 + 血压掉」被发现；诱因可能是剧烈运动、正压通气或胸腔穿刺后。这些都自洽，且教学价值更高。

### 4.2 槽位兼容矩阵（表 4-A，节选）

| core | 允许主诉 | 允许基础疾病 | 允许诱因 | 禁止共存 |
|---|---|---|---|---|
| 原发性张力性气胸 | 突发胸痛／突发呼吸困难 | 无／瘦高体型／吸烟／既往同侧气胸 | 剧烈运动／剧烈咳嗽／无明确诱因／正压通气／胸腔穿刺后 | 同侧大量胸腔积液；同时发生急性心肌梗死（除白名单） |
| 急性左心衰 | 夜间憋醒／不能平卧／粉红色泡沫痰 | 冠心病／高血压／瓣膜病／房颤／慢性心衰 | 输液过快／感染／停药／房颤快心室率／摄盐过多 | 单侧呼吸音消失且气管移位；年龄<30 且无心脏基础 |
| 脓毒症／脓毒症休克 | 发热寒战／精神差／尿少／伤口红肿 | 糖尿病／肿瘤化疗后／长期留置导管／肝硬化／免疫抑制 | 肺／尿／腹腔／皮肤软组织／导管相关感染 | 无任何感染灶线索（须显式标注「来源不明并继续寻找」） |

### 4.3 硬约束规则表（表 4-B）

违反任一条即生成失败，必须重掷，以可执行断言实现。

| 编号 | 规则 | 理由 |
|---|---|---|
| R1 | 主诉属 core 允许集 | 防「气胸主诉黑便」 |
| R2 | 基础疾病年龄可信（`B.minAge ≤ age ≤ B.maxAge`） | 防「19 岁陈旧性心梗合并慢阻肺」 |
| R3 | 性别专属疾病匹配 | 基本一致性 |
| R4 | 诱因先于症状且在该机制合理潜伏期内 | 见表 4-D |
| R5 | 诱因与 core 有已知机制联系 | 防无机制的因果暗示 |
| R6 | 用药史与基础疾病匹配（每种药须有对应适应证） | 防「无糖尿病却用胰岛素」 |
| R7 | 突发变化在 core 的进展树上可达 | 防「气胸突然变成脑出血」 |
| R8 | 检查结果落在 core 值域内 | 防数值与诊断冲突 |
| R9 | 生理耦合方向一致（见表 4-C） | 最常见的生成事故源 |
| R10 | 禁止共存诊断不同现 | 见表 4-A |
| R11 | 每个异常结果必须有归因字段 | 不允许无解释的异常值 |
| R12 | 关键处理必在可选动作中 | 防「正确答案不在选项里」 |
| R13 | ≥1 项信息缺失且存在合法补齐路径 | 有训练价值且不设死局 |
| R14 | 稀有组合需教师白名单 | 稀有病例只能人工写入 |

### 4.4 生理耦合一致性（表 4-C）

约束**方向与联动**，不约束精确数值（阈值一律需复核）。

| 编号 | 状态 | 必须同向 | 不允许的组合 |
|---|---|---|---|
| C1 | 循环灌注不足 | 血压下降、心率增快、尿量减少、外周凉、毛细血管再充盈延长、乳酸升高、意识改变 | 血压 70/40 而尿量乳酸正常且神清面色红润。心率不增快须给解释字段（β 受体阻滞剂／起搏器／传导阻滞） |
| C2 | 张力性气胸 | 患侧呼吸音消失或减弱、患侧叩诊过清音、气管向对侧移位、颈静脉充盈、血压与血氧下降 | 双侧呼吸音对称清晰而诊断张力性气胸 |
| C3 | 心源性肺水肿 | 双肺湿性啰音（多对称、可伴哮鸣）、端坐呼吸、血氧下降、颈静脉充盈或肝颈静脉回流征、可闻奔马律 | 单侧呼吸音完全消失 + 气管移位；同时存在明显容量不足体征 |
| C4 | 二氧化碳蓄积 | 意识改变（嗜睡→昏睡）、PaCO₂ 升高伴 pH 下降（急性）、可有球结膜水肿（**肺性脑病体征表述需要临床教师复核**） | PaCO₂ 显著升高而 pH 明显升高（除慢性代偿另有原因并写明） |
| C5 | 消化道出血伴容量不足 | 血压下降或体位性变化、心率增快、血红蛋白在复苏后下降、尿素氮升高、便色改变 | 急性大出血 30 min 即血红蛋白显著下降且无输液史（滞后性是重要教学点） |
| C6 | 低血糖 | 血糖低于阈值、可有出汗心慌（长期糖尿病者可缺失）、意识改变、给糖后改善 | 血糖正常而「给糖后改善」（伪因果） |
| C7 | 感染性器官功能障碍 | 感染灶存在、炎症指标方向一致、受累器官指标异常（氧合／肌酐／胆红素／血小板／凝血／意识） | 无任何感染证据而诊断脓毒症；器官指标全正常而诊断休克 |
| C8 | 急性肾损伤 | 尿量减少和/或肌酐上升 + 病因字段（肾前／肾性／肾后） | 肌酐显著升高而无任何病因字段（违反 R11） |
| C9 | 快速房颤致心衰加重 | 心率快且不规则、脉搏短绌、心衰体征加重 | 心电图示规整窦性而描述脉搏短绌 |
| C10 | 药物影响 | 用药史→相应效应（β 受体阻滞剂钝化心率、利尿剂致低钾、抗凝致出血倾向） | 使用抗凝药而凝血指标与出血表现完全无关联 |

### 4.5 时间轴一致性（表 4-D）

| 编号 | 规则 | 正例／反例 |
|---|---|---|
| D1 | 诱因→症状符合该机制潜伏期 | 正：剧烈运动→数秒至数分钟内胸痛。反：三周前打球→今晚突发气胸并归因于打球 |

| D3 | 检查窗口：结果只在特定时间窗成立 | 心肌损伤标志物动态须与发病时间匹配；急性出血早期血红蛋白可正常（**时间窗需要临床教师复核**） |
| D4 | 处理→反应起效时间合理 | 正：穿刺减压后数分钟内血压与呼吸改善。反：口服药 3 min 后休克逆转 |

| D6 | 玩家延迟映射到时间轴而非骰子 | 未减压的张力性气胸按 `deteriorationCurve(t)` 推进，不做随机死亡判定 |

### 4.6 校验器与三重保障

```js
function generateCase(seed, difficulty) {
  const core = pickCore(seed, difficulty);
  for (let i = 0; i < 5; i++) {
    const c = fill(core, seed + i), rep = validate(c);   // R1-R14 + C1-C10 + D1-D6
    if (rep.ok) return c;
    LOG.push({ core: core.id, i, failed: rep.failedRules, snapshot: c });
  }
  return core.fallbackCase;                              // 教师手写，100% 自洽
}
```

① **生成期校验**：全部规则，自动。② **抽样人工审核**：每个 core 上线前随机生成 30 例导出 Markdown，教师逐例签署「自洽／需修改／拒绝」，通过率 ≥28/30 方可上线。③ **运行期日志**：玩家可点「这个病例不合逻辑」连同种子上报；**确定性生成**（种子决定一切），教师后台可完整复现。

### 4.7 难度调节：调约束，不调概率

| 杠杆 | 低难度 | 高难度 |
|---|---|---|
| 信息可得性 | 缺 1 项且有明显补齐路径 | 缺 3—4 项，含 1 项永久不可得 |
| 时间预算 | 宽松 20% | 收紧 15% |
| 并发度 | 单线程 | 引入 E4 多患者 |
| 表现典型度 | 典型 | 非典型（老年感染无发热、糖尿病者心肌缺血疼痛不明显——**比例需要临床教师复核**） |
| 干扰线索 | 无 | 1—2 条真实但无鉴别价值的异常（复盘会解释为何无价值） |
| 上级可及性 | 呼叫后 5 min 到 | 上级在手术台上，口头指导 + 20 min 后到 |

**禁止的难度手段**：随机猝死、隐藏的正确答案、必须记忆罕见病才能通过、惩罚求助。

## 5. 决策系统

| 动作 | 临床含义 | 必须附带参数（**不允许空选**） |
|---|---|---|
| **A 继续观察** | 判断暂不需干预但需主动监测 | 观察指标（≥2 项）+ 复评间隔 + 升级阈值 |
| **B 补充检查** | 用信息换确定性 | 项目 + 目的（要区分哪两个诊断）+ 是否需转运 |
| **C 立即处理** | 不等诊断明确，先针对危及生命的病理生理 | 处理内容 + 目标终点 + 复评时点 |
| **D 请求支援** | 呼叫上级／专科／护理／兄弟科室 | 对象 + 结构化交代（现况/背景/评估/请求）+ 期望到达时间 |

「继续观察必须填参数」是刻意设计：临床上最危险的不是选择观察，而是「观察」成了不作为的同义词。写出「观察什么、多久看一次、什么情况叫我」本身就是可评分的教学内容。

**三维消耗**：时间（按层预算，全夜约 720 min，不可恢复）；精力（0—100，起始 85，只影响信息可见性）；资源（初始：监护床位券 ×2、抢救室位 ×1、上级呼叫 ×3、护理协助 ×5、床旁超声 ×3、急查检验通道 ×4、影像通道 ×2、血制品申请 ×1、专科会诊 ×2）。

### 5.1 代价—收益矩阵（表 5-A）

| 动作 | 时间 | 精力 | 资源 | 收益 | 代价 | 最适条件 |
|---|---|---|---|---|---|---|
| A 观察（含参数） | 5—10 + 复评 10 | 3 | 护理 0—1 | 避免过度检查与治疗；获得病程动态这一诊断信息 | 若为时间敏感型，**每个观察周期都在消耗不可逆窗口** | U 低—中、T 低；或已处理后评估反应 |
| A′ 空泛观察 | 5 | 3 | 0 | 无 | 标记「无监测计划的观察」，归入流程缺口 | 无——本项只为暴露该行为 |
| B 床旁检查（心电图/血气/超声/血糖/尿检） | 5—15 | 5 | 急查或超声 ×1 | 高性价比，多数能直接改变处理 | 无目的则记为无适应证检查 | 几乎所有 U 中—高情形，**优先于离床检查** |

| C′ 保护性处理（给氧、开静脉、上监护、抬高床头、备血） | 5—10 | 5 | 护理 ×1 | 极高性价比，几乎无害，为后续留余地 | 极低 | **默认应做**；遗漏时系统显著提示 |
| D 上级 | 3 + 等 5—20 | **−2（焦虑下降）** | 呼叫 ×1 | 决策背书、上级可执行操作、资源协调权 | 额度有限；过度呼叫仅轻度提示「独立判断机会未使用」 | U 高／T 高／需上级权限／涉及知情同意与治疗目标 |

### 5.2 收益条件化：U×T 四象限

U＝不确定度（按已获鉴别性信息量计算）；T＝时间敏感度（由 core 恶化曲线决定）。界面不显示数值（否则变成解谜），但复盘时回放每个决策点当时的 U/T 并解释推荐动作——现场靠直觉，复盘得框架。

| 象限 | 特征 | 主导动作 | 常见错误 | 结算权重 |
|---|---|---|---|---|
| Ⅰ U 高／T 高 | 不知道是什么，但明显要出事 | **C′ + C + D**：保护性处理 + 针对最致命可逆病因 + 呼叫上级 | 停在 B 等检查；反复问病史 | 「未及时求助」「未做保护性处理」为最高权重扣分项 |
| Ⅱ U 低／T 高 | 知道是什么，且要马上做 | **C**，处理后再补 B 确认 | 「先做个检查确认一下」——张力性气胸等胸片是典型反面 | 关键处理时点直接决定结局 |
| Ⅲ U 高／T 低 | 不清楚，但还稳 | **B（床旁优先）→ A（带参数）** | 立即上大检查；过度处理 | 检查适应证与顺序 |
| Ⅳ U 低／T 低 | 清楚且不急 | **A + 交班标注** | 过度检查用药；深夜叫上级处理可延后事项 | 资源节约与交班完整性 |

**组合动作**：允许「1 个主动作 + ≤2 个并行副动作」（副动作限护理委派、C′、呼叫），训练**边稳定边诊断边求助**的并行思维。主动作全额计时，副动作按 30% 计时；精力 <30 时最多 1 个并行动作（属信息层面限制，非能力惩罚）。

### 5.3 求助时机的专门度量

每个 core 由教师标注 `advisableHelpWindow`：张力性气胸合并休克→识别到血流动力学不稳定即刻（需上级协助闭式引流、可能需胸外科）；脓毒症休克→初判即休克或液体复苏后血压仍不达目标（涉及血管活性药、监护升级、可能 ICU）；上消化道大出血→判定活动性大出血时（需内镜团队、输血、可能介入/外科）；意识障碍病因未明→完成可逆病因快速筛查后仍未明。

三档反馈（无羞辱措辞）：**及时**→「求助时点恰当」；**偏早**→「可先完成初步评估再呼叫，以便交代更清楚」（轻提示）；**偏晚**→列为学习报告首要复盘点。**设计倾向写入规则文档：偏晚惩罚权重 = 偏早的 4 倍。** 理由——规培阶段宁愿培养「叫得勤」的医生，不要培养「硬撑」的医生。

## 6. 成长系统

**铁律：经验解锁信息与策略，不解锁能力。** 多数 Roguelike 用永久属性成长提供正反馈，但在医学教学中这会灌输危险隐喻：**临床能力是等级，等级高就治得好，患者结局取决于医生的数值而非判断与体系支持**。

| 允许 | 禁止 |
|---|---|
| 解锁**图鉴条目**（可查阅的知识卡片） | ✗ 提高抢救成功率 |
| 解锁**已见线索的即时标注**（再遇「气管移位」时提示「你在第 3 局见过」） | ✗ 降低并发症发生率 |
| 解锁**更结构化的动作模板**（求助模板、观察参数模板） | ✗ 提高时间/精力/资源上限（上限由班次配置决定，与等级无关） |
| 解锁**复盘深度**、**难度选项**；记录**决策模式画像** | ✗ 缩短检查等待或上级到达时间；✗ 让患者「更耐受延误」；✗ 任何属性点、装备、被动技能 |

成长界面顶部固定一句：

> 你的成长不会让患者更容易好起来。它只会让你更早看清情况、更清楚该问谁、更明白自己在赌什么。

**知识图鉴**通过「真实遇到并处理过」解锁，不可用积分购买；**分片解锁**：见过→识别；正确处理过→处理流程；遇到并发症→并发症；在特殊人群中遇到→特殊人群。重玩的收获是新的表现形态而非数值。

```
【张力性气胸】
├ 本质：胸腔内压持续升高压迫纵隔与大血管，回心血量下降
├ 我遇到的形态：第 3 局 24 岁男性打球后胸痛+呼吸困难，血压 78/50
│               第 7 局 慢阻肺机械通气中血压骤降、气道压升高
├ 关键决策节点：血流动力学不稳定时不等影像，先减压
├ 我的延误史：等胸片（第 3 局，延迟 22 min）
├ 教材对应：《内科学》气胸；《诊断学》胸部检查（叩诊/听诊/气管位置）
├ 待复核：穿刺减压部位与器材规格（需要临床教师复核）
└ 解锁：识别✓ 处理流程✓ 并发症（复张性肺水肿）✓ 特殊人群✗
```

**内容纪律**：只写通行教学表述，不写剂量、页码、指南推荐等级。不确定处以「需要临床教师复核」占位，且该占位在教师签署前**在游戏内可见**——让学员知道哪些内容尚未定稿，本身也是科学态度的示范。

**疾病线索册**按体征/症状组织（《诊断学》导向），核心是「不能区分什么」这一列，直接对抗最常见的思维缺陷——**把某个体征当成某个诊断的同义词**：气管向对侧移位→能区分「同侧胸腔压力增高」，不能区分气胸 vs 大量积液（需结合叩诊音）；颈静脉充盈→能提示回心/右心受阻或容量过多，不能区分心衰 vs 气胸 vs 心包积液；双肺湿性啰音→能提示肺内液体，不能区分心源性 vs 非心源性；尿素氮升高伴肌酐轻升→能提示上消化道出血或容量不足，不能确定出血部位。

**决策经验只统计过程，不统计结局**（不统计救活率，避免结局导向的错误学习）：保护性处理覆盖率 72%（中位数 80%，常漏「开通静脉」与「心电监护」）；观察参数完整率 41%（55%，「升级阈值」最常缺失）；床旁检查优先率 63%（60%）；**首次求助时点偏差 +18 min（+6 min，首要改进项）**；委派使用率 30%（65%，倾向自己硬跑）；交班完整率 78%（70%）。仅玩家与其带教可见，**不做排行榜**。

**反通关设计**：① core 填充空间足够大，高经验玩家仍会遇到未见形态（无发热的老年脓毒症、以晕厥为唯一主诉的肺栓塞）；② 难度由玩家显式选择，不随解锁自动提升；③ 每 10 局插入**校准局**，关闭全部即时标注回到零提示，检验真实判断力——这是带教最应关注的数据。

## 7. 道具与能力设计

每项必须是真实存在的临床资源、工具或行为。**禁止**：透视诊断、时间回溯、复活、无限求助、自动诊断、提高成功率的被动加成、任何魔法隐喻命名。

| 名称 | 医学含义 | 效果 | 消耗与限制 | 误用后果 |
|---|---|---|---|---|
| **上级医师电话** | 请求上级支援；层级会诊制度 | 决策建议；上级到场可执行超出自身权限的操作；协调资源 | 呼叫 ×1、3 min；全夜 3 次；上级可能在手术中，返回口头指导 + 延迟到场 | 无实质惩罚，仅提示「可先完成初步评估以便交代清楚」 |
| **护士协作（口头医嘱）** | 与护理团队协作，委派具体操作 | 并行完成：给氧、上监护、开静脉、测血糖、留标本、备抢救车、记尿量 | 护理 ×1、1 min；必须具体（含目标与回报点），否则被追问并重复耗时 | 模糊委派→执行偏差，记为沟通缺口 |
| **床旁超声机** | 床旁即时超声：容量、心脏收缩、胸腔积液/气胸、腹腔积液 | 5 min 获得结构性信息，无需转运 | 超声 ×1；全夜 3 次；可能被借走（E5）。**适用场景与操作规范需要临床教师复核** | 过度解读→提示「该结论需上级确认」 |
| **床旁血气分析** | 评估氧合、通气、酸碱与乳酸 | 5—8 min 出结果 | 急查通道 ×1；需动脉采血 | 无适应证反复送检→记为过度检查 |
| **快速床旁检验（血糖／尿常规／心电图机）** | 最基础、最高性价比的即时手段 | 1—5 min 出结果 | 时间极低，不占急查通道；心电图机可能缺纸（E5） | 意识障碍未测血糖→复盘列为高权重遗漏 |
| **抢救车** | 抢救药品与器械集中配置 | 使抢救类处理成为可选动作 | 护理 ×1 取车、2 min；抢救室外需先取车 | 未提前准备→延迟计入时间轴 |
| **监护床位券** | 连续心电、血氧、血压监护床位 | 患者进入「连续监测态」，变化会主动提示 | 全夜 2 张，给了 A 就没有 B | 给低危→高危变化无法被及时发现（因果清晰，可复盘） |
| **专科会诊单** | 消化内镜、心内介入、胸外、ICU、麻醉气道支持 | 20—40 min 后执行专科操作 | 会诊 ×1、5 min；须说明目的与当前状态 | 未先稳定即等会诊→时间轴推进 |
| **既往病历调阅** | 调阅本院历史记录 | 补齐基础疾病、用药、过敏史、检查基线 | 10 min；仅本院有记录者可得（外院患者属 E3 永久缺失） | 忽略此渠道→本可避免的信息缺口 |
| **诊疗规范手册** | 查阅规范、评分表、流程图 | 打开知识卡片；给出「要点核查清单」 | 5 min（休息点免费）；不给诊断答案，只给核查项 | 无 |
| **交班本** | 手写/电子交接记录 | 记录未完成事项；晨交班按完整度评价 | 每条 1 min；未记录事项在晨交班「想不起来」 | 交班完整率下降 |
| **咖啡／进食／坐下** | 值班者自我照护 | 精力 +8～+15 | 5—10 min；单局 ≤3 次，第 3 次收益减半。**不设副作用惩罚，避免污名化休息** | 无 |

**始终可用的能力**（非消耗品）：结构化求助表达（四段式，使上级建议更有针对性——属**信息质量提升**，不是成功率加成）；重新体格检查（5 min，识破 E5 伪数据的主要途径）；写出「我的假设与我在赌什么」（不耗时，复盘时最有价值）；告知家属并留联系方式（降低 E6 权重，因为它本就该做）；说「我不确定，需要上级看一下」（**系统永不惩罚**）。

## 8. Boss 病例设计

**术语纪律**：代码内用 `boss` 标识，**界面一律不出现「Boss／击败／通关」**。玩家看到的是「凌晨 2:40 · 抢救室 · 危重病例」；结算写「本次抢救过程记录」。Boss 的本质是多阶段、多线程、需要求助的综合病例；其「弱点」不是数值弱点，而是**关键决策节点（CDP）**——在正确时点做出正确类别的动作即可改变时间轴。

### 8.1 Boss-1｜张力性气胸合并休克的年轻患者

男 24 岁，篮球活动后 40 min 突发左侧胸痛伴呼吸困难。既往体健，瘦高体型，吸烟半年。到院烦躁、大汗、呼吸急促，血压偏低并进行性下降。

| 阶段 | 呈现 | 关键决策节点（弱点） | 延误后果 |
|---|---|---|---|
| P1 识别（0—5 min） | 主诉 + 一般情况；桌上已放好胸片申请单 | **CDP-1：先做即时体格检查而非等胸片**——识别患侧呼吸音消失/减弱、叩诊过清音、气管向对侧移位、颈静脉充盈 | 时间轴推进，血压继续下降 |
| P2 决断（5—15 min） | 血压与血氧进一步下降，更烦躁 | **CDP-2：判定张力性气胸并立即胸腔穿刺减压——不等影像。** 并行：给氧、开静脉、上监护、呼叫上级 | 进入 P3，部分处理窗口关闭 |
| P3 循环衰竭（仅延误时） | 意识下降，脉搏细弱，血压测不清 | **CDP-3：仍以减压为第一优先，不可只补液与升压。** 呼叫上级为强制项 | 进入不可逆分支（见 8.4） |
| P4 确定性处理 | 减压后症状体征改善，血压回升 | **CDP-4：减压是临时措施，需继续胸腔闭式引流**（可能需上级/胸外科到场）；复查影像确认位置与复张 | 张力再形成，症状复现 |
| P5 复张后管理 | 可能出现持续漏气、引流不畅、**复张性肺水肿**（同侧新发湿性啰音、氧合下降） | **CDP-5：不把「管子放了」当成结束**——识别新发问题，调整氧疗并报告上级 | 氧合恶化 |
| P6 沟通与交接 | 家属赶到，问「会不会有事」「要不要开刀」 | **CDP-6：告知病情/已做处理/下一步与风险；交班记录（引流护理、复查、复发教育、戒烟建议）** | 交班完整率下降，E6 触发 |

张力性气胸是**临床诊断**，其教学价值恰在于「唯一一次我们明确要求你不要等检查」。**穿刺减压的部位、进针方式、器材与引流规格需要临床教师复核，游戏内不给操作细节。** 教材对应：《内科学》气胸；《诊断学》胸部体格检查与休克识别。

### 8.2 Boss-2｜多器官功能障碍的脓毒症

女 68 岁，2 型糖尿病 12 年，「畏寒发热 1 天、精神差、尿少」，近 3 天腰痛尿频（来源可随机替换为肺/腹腔/软组织/导管）。到院体温升高（**高难度变体：体温正常甚至偏低**），心率增快，血压偏低，意识淡漠。

| 阶段 | 呈现 | 关键决策节点 | 延误后果 |
|---|---|---|---|
| P1 识别器官功能障碍 | 感染征象 + 意识改变 + 尿少 + 呼吸增快 | **CDP-1：把「发热+精神差+尿少」识别为感染导致的器官功能障碍**，而非「普通尿路感染」；建立监护、测乳酸、评估灌注 | 进入休克阶段 |
| P2 初始处置 | 血压持续偏低 | **CDP-2：留取病原学标本后尽早经验性抗感染 + 液体复苏 + 寻找感染源。** 核心张力：「先留标本再用药，但不为留标本而延误用药」 | 器官功能进一步恶化 |
| P3 液体反应性 | 补液后血压部分回升或不回升；氧合下降 | **CDP-3：不盲目继续大量补液**，评估反应性与容量耐受（临床征象+床旁超声+氧合）；无反应→升压药与更高监护级别→**呼叫上级/ICU** | 肺水肿或持续低灌注 |
| P4 感染源控制 | 影像提示可能需引流的病灶 | **CDP-4：抗生素不能替代源头控制**，激活相应专科（泌尿/普外/介入） | 抗感染无效 |
| P5 继发器官损害 | 急性肾损伤、凝血异常、氧合恶化 | **CDP-5：多器官同时受累时的优先级排序与监护升级；识别需器官支持的时点** | 进入不可逆分支 |
| P6 治疗目标与沟通 | 家属询问预后；高龄多病者涉及治疗强度 | **CDP-6：以可理解语言说明严重程度、不确定性与下一步；治疗目标决策必须由上级主导并记录。** 规培医师**不得**独自决定治疗强度限制 | 沟通缺口，E6 高权重 |

**复核标记**：脓毒症定义框架与处置顺序按教材通行表述编写；**时间捆绑要求、液体量、平均动脉压目标、首选升压药、抗生素选择全部需要临床教师复核，游戏内只给动作类别与顺序逻辑，不给数值指令。** 教材对应：《内科学》感染性疾病总论及相关系统感染、休克、急性肾损伤、DIC；《诊断学》发热、意识障碍与休克评估。

### 8.3 Boss-3｜同时三名患者恶化的夜班高峰

本作真正的核心 Boss——考的不是任何单一疾病，而是分诊、委派、求助与资源分配。凌晨 2:40，30 秒内三条呼叫：甲 12 床男 76 慢阻肺「血氧掉到 85，人有点糊」（实为二氧化碳蓄积伴早期意识改变，**时间敏感度高**，需评估无创通气指征）；乙 3 床女 62 冠心病史「说胸口压得慌，出汗」（急性冠脉综合征可能，**极高**，需 10 min 内心电图）；丙留观 5 床男 45 酒精性肝病「家属说人叫不应了」（肝性脑病，诱因便秘 + 感染，**中**，但须先排除低血糖与颅内事件）。

| 阶段 | 机制 | 关键决策节点 |
|---|---|---|
| P1 30 秒分诊 | 三条同时显示，计时开始 | **CDP-1：正确策略不是单选，而是委派 + 并行**——对甲要求护士调整氧疗并备血气；对乙要求 10 min 内心电图并备抢救车与监护；对丙要求立即测血糖与生命体征。然后**亲自先去乙**（时间敏感度最高且需医师判读心电图） |
| P2 并行推进 | 三线各按时间轴前进，玩家只能在一处 | **CDP-2：呼叫上级并明确分工。此处「未求助」是最高权重扣分项** |
| P3 资源冲突 | 只剩 1 张监护床券，甲乙都需要 | **CDP-3：显式排序并给理由；对未获者制定替代方案**（专人守护、缩短复评、明确升级阈值） |
| P4 意外反转 | 丙的血糖回报为低值（40% 分支）→ 丙从「中」升为「高」且**高度可逆** | **CDP-4：接受新信息并重排优先级**；低血糖处理是本局最快见效、最不该错过的干预（**给糖方案需要临床教师复核**） |
| P5 收束 | 三线达阶段性稳定或需转出 | **CDP-5：三份交接、三方告知、清点未完成事项** |

评价顺序：① 是否委派；② 首次求助时点；③ 排序是否依时间敏感度而非呼叫顺序；④ 稀缺资源理由是否可辩护；⑤ 是否对「未去看的患者」给出监测与升级方案。**明确不设**「三人全部转危为安」的额外奖励或胜利特效——防止玩家把多患者危机体验为爽点。

### 8.4 不可逆分支与死亡的处理（强制规范）

延误累积到 `irreversiblePoint` 时：① **无戏剧化**——不用心跳线拉平动画、不用音效、不闪红屏，界面转为低饱和灰蓝、动效放慢；② **过程如实**——如实描述抢救与团队行为，不省略也不渲染；③ **不出现「失败」字样**——文案为「患者于 03:52 经抢救无效死亡」，随后「请完成死亡记录与家属告知」，**它是需要继续履行职责的临床事件，不是游戏状态**；④ **强制两个不可跳过节点**——家属告知、死亡记录；⑤ **跑局继续**至晨交班；⑥ **复盘以 M&M 框架呈现**，聚焦系统与决策，不做人格评价。

**扩展位（须教师撰写并签署后上线）**：B-4 大量呕血的肝硬化患者（容量复苏优先于内镜时机、气道保护、多团队协作）；B-5 急性冠脉综合征的再灌注时间管理；B-6 晨交班（结构化交接，失败＝信息丢失）。

## 9. 五个随机病例模板

各库为节选，条目并非自由组合——受第 4 章 ACFV 约束：先锚定 core，再在该 core 允许集内取值。「→」后为适配 core。

### 9.1 T1 急性呼吸困难

**core**：急性左心衰｜慢阻肺急性加重｜哮喘急性发作｜肺栓塞｜气胸（含张力性）｜重症肺炎

| 库 | 条目（节选） |
|---|---|
| 主诉 | 夜间憋醒不能平卧→左心衰；咳痰加重气促 3 天→慢阻肺/肺炎；突然喘不上气说不出整句→哮喘/气胸/肺栓塞；突发胸痛伴呼吸困难→气胸/肺栓塞；起床后眼前发黑气促→肺栓塞 |
| 基础疾病 | 冠心病/高血压/瓣膜病/房颤→左心衰；长期吸烟、慢阻肺→慢阻肺加重、继发性气胸；哮喘/过敏性鼻炎→哮喘；近期术后/长期卧床/恶性肿瘤/既往血栓→肺栓塞；瘦高体型/既往同侧气胸→原发性气胸；糖尿病/高龄/吞咽差→肺炎 |
| 诱因 | 输液过快/摄盐过多/停用利尿剂→左心衰；上呼吸道感染/冷空气/停用吸入药→慢阻肺、哮喘；接触过敏原→哮喘；制动后首次下床→肺栓塞；剧烈运动/剧烈咳嗽/正压通气→气胸；误吸→肺炎 |
| 检查结果 | 双肺对称湿性啰音+颈静脉充盈+端坐呼吸+奔马律→左心衰；桶状胸+呼气延长+双肺哮鸣+血气示通气障碍→慢阻肺；弥漫哮鸣+吸入支气管舒张剂后改善→哮喘；一侧呼吸音消失+患侧叩诊过清音+气管移位→气胸；呼吸急促而肺部听诊相对干净+心电图右心受累+下肢不对称肿胀→肺栓塞；局限湿性啰音+影像实变+炎症指标升高→肺炎 |
| 突发变化 | 血氧持续下降、粉红色泡沫痰增多→左心衰；意识由清转嗜睡+血气二氧化碳升高→慢阻肺；哮鸣反而减弱、说话不能、辅助呼吸肌明显参与→哮喘重症化；血压骤降+气管移位明显→张力性气胸；突发晕厥+氧合骤降→大面积肺栓塞；低血压与尿少→肺炎进展为脓毒症 |

**自洽校验**：V1-1 F 含「一侧呼吸音消失+气管移位」则 core 必为气胸类，禁止同现「双肺对称湿性啰音」；V1-2 core=肺栓塞时 B 或 T 至少一项为危险因素，否则须显式标为少见形态并需教师白名单；V1-3 core=左心衰时 B 至少一项心脏基础成立，年龄<30 且无心脏基础禁止生成；V1-4 慢阻肺加重可进展至二氧化碳蓄积性意识改变，**不可**直接进展为气管移位；V1-5「吸入支气管舒张剂后明显改善」只能出现在哮喘类，慢阻肺者可部分改善但不得写为完全缓解（**可逆性描述需要临床教师复核**）；V1-6 氧合/意识/血压方向须满足 C1—C4。

### 9.2 T2 急性胸痛

**core**：急性冠脉综合征｜主动脉夹层｜肺栓塞｜张力性气胸｜急性心包炎｜非致命性（食管/肌肉骨骼/焦虑相关）

| 库 | 条目（节选） |
|---|---|
| 主诉 | 胸骨后压迫闷痛持续不缓解伴出汗→急性冠脉综合征；突发撕裂样剧痛向背部转移→夹层；突发胸痛伴呼吸困难→肺栓塞/气胸；与呼吸体位相关、前倾坐位减轻→心包炎；进食后胸骨后烧灼感→食管相关；局部按压痛→肌肉骨骼 |
| 基础疾病 | 高血压/糖尿病/高脂血症/吸烟/早发冠心病家族史→急性冠脉综合征、夹层；长期血压控制不佳→夹层（**结缔组织病关联需要临床教师复核**）；近期手术或制动或肿瘤→肺栓塞；瘦高青年/既往气胸→气胸；近期病毒感染史→心包炎；反流性食管病→食管相关 |
| 诱因 | 情绪激动/体力活动/寒冷/饱餐→急性冠脉综合征；血压骤升/用力→夹层；久坐后活动→肺栓塞；剧烈运动或咳嗽→气胸；感染后 1—2 周→心包炎；饮酒/暴食/平卧→食管相关 |
| 检查结果 | 心电图动态改变+心肌损伤标志物动态升高→急性冠脉综合征（**判读标准与时间窗需要临床教师复核**）；双上肢血压差异+脉搏不对称+影像提示主动脉病变→夹层；血氧下降+心电图右心受累+D-二聚体升高（阴性价值更大）→肺栓塞；单侧呼吸音消失+叩诊过清音+气管移位→张力性气胸；心包摩擦音+心电图广泛改变→心包炎；各项基本正常+压痛点明确→非致命性 |
| 突发变化 | 急性肺水肿/心律失常/血压下降→急性冠脉综合征；意识改变、一侧肢体活动异常、心包积液征象→夹层并发症；突发晕厥+血压下降→肺栓塞；血压骤降+颈静脉充盈→张力性气胸；心包积液增多+脉压变窄→心包积液压迫；症状自行缓解→非致命性 |

**自洽校验**：V2-1 每例**必须**在可选动作中包含「10 min 内床旁心电图」；V2-2 core=夹层时禁止在初始信息中直接给出诊断性影像结论；V2-3 core=非致命性时禁止设计为「陷阱以惩罚检查」，做心电图与基本评估不计过度检查；V2-4「胸痛+心电图正常」不得作为排除急性冠脉综合征的依据，若生成此组合，复盘必须含该教学点；V2-5 E 须与 core 并发症谱一致（心包炎可进展为心包积液压迫，**不可**进展为气管移位）；V2-6 抗凝/抗血小板类处理在「疑似夹层未排除」时须触发系统追问（**表述需要临床教师复核**）。

### 9.3 T3 急性意识障碍

**core**：低血糖｜二氧化碳蓄积（肺性脑病）｜肝性脑病｜电解质紊乱（如低钠）｜感染性｜脑血管事件｜药物/酒精相关

| 库 | 条目（节选） |
|---|---|
| 主诉 | 叫不醒/喊不应→全部；胡言乱语行为异常→肝性脑病/低血糖/电解质/感染性；出汗心慌后意识模糊→低血糖；白天嗜睡夜里烦躁→二氧化碳蓄积/肝性脑病；突发一侧肢体无力伴言语不清→脑血管事件；抽搐后未清醒→低血糖/电解质/脑血管事件 |
| 基础疾病 | 2 型糖尿病用胰岛素或磺脲类/慢性肾功能不全/高龄→低血糖；慢阻肺/家庭氧疗→二氧化碳蓄积；肝硬化/脾大→肝性脑病；长期利尿剂/肿瘤/慢性腹泻呕吐→电解质；糖尿病/留置导管/免疫抑制→感染性；高血压/房颤/既往脑血管病→脑血管事件；长期饮酒/镇静催眠药→药物酒精相关 |
| 诱因 | 进食减少/呕吐/剂量未调整/饮酒→低血糖；感染/不当高浓度吸氧/镇静药→二氧化碳蓄积（**机制表述需要临床教师复核**）；感染/消化道出血/便秘/电解质紊乱/大量蛋白摄入/镇静药→肝性脑病；加用或加量利尿剂/大量饮水→低钠；新发感染灶→感染性；血压骤升/房颤未抗凝→脑血管事件 |
| 检查结果 | 血糖低值+给糖后改善→低血糖；血气二氧化碳升高伴 pH 下降+球结膜水肿→二氧化碳蓄积；扑翼样震颤+肝病体征（黄染/腹壁静脉/腹水）+血氨可升高→肝性脑病（**血氨与病情相关性表述需要临床教师复核**）；血钠明显降低+尿渗与血渗关系异常→低钠；感染灶+器官功能异常+乳酸升高→感染性；一侧肌力下降+病理征+影像见病灶→脑血管事件 |
| 突发变化 | 抽搐、意识进一步下降→低血糖/电解质/脑血管事件；呼吸变浅、二氧化碳继续升高→二氧化碳蓄积；呕血黑便（出血为诱因且仍在进行）→肝性脑病；呕吐后误吸、氧合下降→全部（气道保护缺失）；血压下降尿少→感染性；瞳孔不等大、呼吸节律改变→脑血管事件需紧急评估 |

**自洽校验**：V3-1 **每例必须把「立即测血糖」置于可选动作首屏**，未测血糖而先做其他检查者复盘列为高权重遗漏；V3-2 F 含「给糖后改善」则血糖值必须为低值（C6，禁伪因果）；V3-3 core=肝性脑病时 B 必含肝病基础且 T 必为已知诱因，**无诱因者需白名单**；V3-4 core=二氧化碳蓄积时 pH 与 PaCO₂ 关系须符合 C4 并标记急性/慢性代偿；V3-5 全部 T3 强制附带 E3 信息缺失且必须存在合法补齐路径（家属/既往病历/随身药物/体检线索）；V3-6 低血糖与高渗高血糖状态不得同现；V3-7「气道保护」动作必须可选，意识明显下降而未评估气道者列为高权重遗漏；V3-8 偏侧体征与影像结论必须互证，矛盾而无解释字段者违反 R11。

### 9.4 T4 发热伴低血压（疑似脓毒症）

**core**：肺源性｜尿源性｜腹腔源性｜皮肤软组织源性｜导管相关｜来源不明（需继续寻找）

| 库 | 条目（节选） |
|---|---|
| 主诉 | 畏寒发热+咳黄痰+气促→肺源性；发热+腰痛+尿频尿急+尿少→尿源性；发热+腹痛腹胀+停止排便排气→腹腔源性；发热+局部红肿热痛破溃→皮肤软组织；发热寒战且与输液/透析时间相关→导管相关；**高难度变体**：不发热，仅「精神差、吃不下、尿少」→全部（老年非典型） |
| 基础疾病 | 糖尿病/慢阻肺/卧床/吞咽困难→肺源性；泌尿系结石/前列腺增生/留置尿管→尿源性；胆道疾病/既往腹部手术/恶性肿瘤→腹腔源性；糖尿病足/外周血管病/免疫抑制→皮肤软组织；长期中心静脉导管/透析通路→导管相关；高龄/多病共存/认知障碍→来源不明 |
| 诱因 | 受凉/误吸→肺源性；尿管更换/结石梗阻/饮水少→尿源性；进食油腻/肠梗阻/术后→腹腔源性；足部外伤/修剪指甲损伤→皮肤软组织；导管护理不当/置管时间长→导管相关 |
| 检查结果 | 局限湿性啰音+影像实变+氧合下降→肺源性；肾区叩击痛+尿检异常+超声见梗阻或积水→尿源性；腹部压痛反跳痛+影像积液或梗阻+胆红素升高→腹腔源性；局部红肿边界+波动感→皮肤软组织；导管入口红肿或无局部体征+血培养提示→导管相关；炎症指标升高但影像与体检未见明确病灶→来源不明；**共同项**：心率增快、血压偏低、尿量减少、乳酸升高、意识淡漠、肌酐上升、血小板下降 |
| 突发变化 | 补液后血压仍不达标（需血管活性药）→全部；氧合迅速恶化→肺源性为主；尿量进一步减少、肌酐继续上升→全部（急性肾损伤）；皮肤瘀点瘀斑、穿刺点渗血（凝血功能障碍）→全部；局部病灶迅速扩展（需紧急外科处理）→皮肤软组织；意识进一步下降→全部 |

**自洽校验**：V4-1 指向脓毒症时**必须**存在可疑感染来源，或显式标注「来源不明」并把「继续寻找来源」列为必做动作；V4-2 器官功能障碍指标至少一项异常，全正常者不得标注为器官功能障碍（C7）；V4-3 血压/心率/尿量/乳酸/意识须满足 C1，心率不增快须给解释字段；V4-4「留取病原学标本」与「经验性抗感染」必须同时可选，系统记录先后顺序与时间差；V4-5 需源头控制的 core 须把「专科会诊/引流」列入可选动作；V4-6 急性肾损伤须附病因字段（C8、R11）；V4-7「无发热变体」占比上限 30%，复盘必须解释「老年人感染可无发热」（**比例需要临床教师复核**）；V4-8 文本不写抗感染药名、剂量、血压目标与液体量，只写动作类别。

### 9.5 T5 上消化道出血

**core**：肝硬化食管胃底变异出血｜消化性溃疡出血｜药物相关黏膜损伤｜恶性肿瘤相关｜黏膜撕裂类（**命名与教学表述需要临床教师复核**）

| 库 | 条目（节选） |
|---|---|
| 主诉 | 呕吐大量鲜红色血伴头晕→变异出血/溃疡；解黑色柏油样便 2 天伴乏力→溃疡/药物相关/肿瘤；呕吐咖啡色胃内容物→溃疡/药物相关；剧烈呕吐后呕血→黏膜撕裂；腹胀加重精神差随后呕血→变异出血伴肝性脑病；体重下降+上腹不适数月+近日黑便→肿瘤相关 |
| 基础疾病 | 肝硬化/脾大/既往变异出血史→变异出血；既往胃十二指肠溃疡/幽门螺杆菌感染史→溃疡；长期服非甾体抗炎药/抗血小板药/抗凝药/糖皮质激素→药物相关；消化道恶性肿瘤病史→肿瘤相关；大量饮酒→黏膜撕裂 |
| 诱因 | 饮酒/粗糙食物/便秘用力/感染/停用降门脉压药→变异出血；饮食不规律/幽门螺杆菌未根除→溃疡；因骨关节疼痛自行服止痛药数日→药物相关；无明确诱因、进展性→肿瘤相关；醉酒后反复剧烈呕吐→黏膜撕裂 |
| 检查结果 | 肝病体征（黄染/腹壁静脉/腹水/脾大）+血小板降低+凝血异常→变异出血；上腹压痛+既往内镜示溃疡→溃疡；用药史明确且无肝病体征→药物相关；消瘦+可及腹部包块+明显贫血→肿瘤相关；**共同项**：心率增快、血压下降或体位性变化、血红蛋白（早期可正常）、尿素氮升高、直肠指检见黑便 |
| 突发变化 | 再次大量呕血+血压进一步下降→全部（活动性出血）；呕血后呛咳+氧合下降→全部（气道风险）；意识改变→变异出血为主；尿量减少+肌酐上升→全部；出现发热→变异出血（出血后感染风险）；血红蛋白在补液后明显下降→全部 |

**自洽校验**：V5-1 core=变异出血时 B 必含肝病基础，无肝病基础则自动改判为溃疡类；V5-2 core=药物相关时用药史须与基础疾病匹配（R6：有骨关节疾病才合理长期服止痛药）；V5-3 禁止「起病 30 min 内血红蛋白已显著下降且无输液史」（C5、D3）；V5-4 尿素氮与肌酐关系须符合上消化道出血特点并附病因字段；V5-5「容量复苏与气道保护」必须可选且优先级高于内镜时机，玩家先选内镜而未稳定时时间轴按 D6 推进（**稳定标准需要临床教师复核**）；V5-6 输血动作只到「申请配血/输注红细胞」类别，**不给阈值与单位数**；V5-7 变异出血须把「预防性抗感染」列为可选并在复盘解释依据（**适用范围与方案需要临床教师复核**）；V5-8「活动性大出血 + 正在使用抗凝药」时必须提供「评估并处理抗凝状态」动作。

**跨模板共享校验**：X1 不得同时锚定两个致命 core（除白名单）；X2 全部异常结果须有归因字段，输出附归因清单供教师抽查；X3 至少 1 项可补齐的信息缺失；X4 `criticalActions` 由教师标注且必在动作列表中；X5 必须标注 `advisableHelpWindow`，无标注不得上线；X6 文本不得含具体药物剂量、输注速度、操作参数，生成器对含数字剂量的字符串做正则拦截。

## 11. 失败复盘机制

**「失败」不等于死亡。** 六类未达标结局**并列展示，不排序为更惨/更轻**：F1 关键处理延误 → 识别缺口/决策优先级；F2 求助延迟 → 能力边界认知；F3 资源错配（稀缺资源给了低风险者致高风险者监测不足）→ 分诊与排序；F4 信息未获取（存在可得而未获取的关键信息，如未测血糖）→ 流程与习惯；F5 沟通缺口（未告知、告知不完整、未记录）→ 沟通与文书；F6 死亡或不可逆损害 → 综合，按 M&M 框架。

**F6 并不总由玩家决策导致**——某些病例在玩家接手时就已接近不可逆点（这是真实的）。复盘会**明确区分**「可避免的延误」与「疾病本身的严重程度」，并直接写出：「本例即使在最优处理下，预后仍高度不确定——这不是你的失败。」规培医师最需要的不是免责，而是准确的因果归因。

**决策日志记录「当时能看见什么」**，而非真实情况——复盘必须在当时的信息条件下评价决策，否则就成了后见之明的批判，违反临床复盘伦理。

```js
{ t:"01:50", layer:"L3", nodeId:"case_ugib_01", caseSeed:"...#c3",
  state:{ known:["黑便2天","心率偏快","血压偏低","止痛药史2周"],
          pending:["血型配血"], unavailable:["外院胃镜报告"],
          hiddenByFatigue:["12床血气回报"] },   // 疲劳态隐藏的信息
  U:0.35, T:0.80,                               // 界面不显示，复盘显示
  chosen:{ type:"A_observe", params:{ indicators:[...], interval:30, threshold:"..." } },
  alternatives:["B_test_CT","C_treat_transfuse","D_help_endoscopy"],
  cost:{ time:10, energy:4 }, outcome:"stable",
  teachingTags:["避免不稳定患者转运","观察参数完整"] }
```

**学习报告三层结构**：① 事实线（时间轴表格，不含评价词）；② 分岔点（自动识别 2—4 个改变选择即显著改变后续时间轴的决策点）；③ 知识点（每个分岔点映射 1—3 个知识点，链接图鉴与教材章节主题，不给页码）。

> **分岔点 ②｜23:30 休息点**
> - 当时状况：精力 5（疲劳阈值 30 以下），队列 2 项，时间尚有余量。
> - 你的选择：简短休息 10 min + 整理队列 20 min。
> - 另一条路：完整休息 30 min（精力 +30，脱离疲劳态），队列推进 1 步（家属焦虑升级，可在 L4 处理）。
> - 实际后果：01:50 触发疲劳漏看，12 床血气延迟 4.5 h 才被处理。
> - 要点：疲劳导致的注意力缺口是夜班最被低估的风险。**队列里的家属沟通可以晚 30 min，血气结果不能晚 4 小时。**「照顾自己」在夜班里是一项临床决策，不是偷懒。

| 分岔点 | 归因 | 知识点 | 教材对应（章节主题） |
|---|---|---|---|
| ① 21:16 是否等胸片 | 决策优先级（做对了） | 张力性气胸属临床诊断；不稳定时先减压 | 《内科学》气胸；《诊断学》胸部检查与休克识别 |
| ② 23:30 休息决策 | 自我状态管理 | 疲劳与注意力遗漏；值班安全 | 需要临床教师复核 |
| ③ 21:20 血气未闭环 | 流程缺口 | 检验结果闭环；危急值处理；慢阻肺加重的通气评估与二氧化碳蓄积识别 | 《内科学》慢阻肺、呼吸功能不全；《诊断学》血气分析基础 |
| ④ L5 遗漏心内 3 床 | 沟通/文书缺口 | 结构化交接；「无事发生的高危患者」同样需交接 | 需要临床教师复核 |

**归因分类器**避免「一律归为知识不足」这种最无用的反馈：**知识缺口**（信息充分时选择与病理生理不符的动作）→ 指向图鉴与教材；**流程缺口**（判断正确但未闭环：结果未追、委派未回报、记录未写）→ 指向核查清单；**资源判断缺口**（排序不可辩护）→ 指向 U×T 象限与分配原则；**沟通缺口**（告知/求助/交班的内容或时点不足）→ 指向结构化模板。

**语言纪律**：「你杀死了患者」→「患者在 03:52 死亡。以下三个决策点可能改变病程走向。」；「愚蠢的选择」→「此处更常见的做法是……原因是……」；「Game Over／你失败了」→「本次夜班结束。以下是复盘报告。」；「恭喜！全员生还！」→「本次夜班全部重点患者达到阶段性稳定。以下是过程评价与可改进点。」；「死亡数 12／存活率 68%」→ 只显示过程指标，不显示结局率。

报告结尾固定一句（不可关闭）：

> 本报告针对决策与流程，不针对你的能力或人格。真实临床中，好的决策也可能有坏的结果；坏的结果也常常源于系统而非个人。如果这份报告让你想找人聊聊，请联系你的带教老师。

## 12. 严肃性设计

本模块的题材是患者的痛苦、恶化与死亡。把这些做成游戏，唯一可接受的理由是**它能让未来的医生更少犯错**。一旦表达方式让玩家把患者伤害体验为刺激、成就或笑料，模块就丧失正当性。因此本章准则具有**否决权**：违反者视为缺陷，必须修正，不接受「玩家喜欢」「数据更好」的理由。

### 12.1 设计准则 P1—P10

| 编号 | 准则 | 具体要求 |
|---|---|---|
| P1 | **患者是人，不是数值容器** | 每例须有姓名占位、年龄、一句生活情境（「退休前是小学教师，孙子刚上一年级」）；界面不得有患者生命值条 |
| P2 | **恶化不设奖励反馈** | 恶化/抢救/死亡场景禁用上扬音效、粒子特效、震动、红屏闪烁、连击计数、成就弹窗；转为低饱和灰蓝、动效放慢、音量降低 |
| P3 | **死亡不是失败状态** | 不出现「Game Over／失败／你输了」；不允许读档重试单个病例 |
| P4 | **死亡后必须履行职责** | 强制两个不可跳过节点：家属告知、死亡记录；跑局继续至晨交班；无「跳过」按钮 |
| P5 | **不量化死亡** | 全局不显示死亡人数、存活率、救治成功率；无排行榜、无全服统计、无分享卡；过程指标仅玩家与带教可见 |
| P6 | **家属情绪不是难度调味料** | 家属场景须有可理解动因（信息不足、恐惧、内疚）；禁止「闹事家属」「医闹」类标签化与喜剧化 |
| P7 | **不娱乐化身体损害** | 不用血液喷溅、创面特写、呕吐物等感官刺激图像；体征以文字与示意图呈现；影像波形可写实但不做惊吓式呈现 |
| P8 | **不用患者做道具** | 不出现「用一个患者换资源」的机制表述；资源分配理由标签为医学理由，不是分数 |
| P9 | **内部术语不泄漏到界面** | `boss/enemy/damage/kill/HP` 仅存于代码；UI 文案由独立词表管理并由教师审核 |
| P10 | **提供退出与支持通道** | 涉及死亡的场景前给出内容提示；允许随时中止并保存；复盘末尾提供带教联系入口（尤其考虑经历过真实不良事件的学员） |

**术语对照（代码 → 界面）**：`boss`→「危重病例」；`defeat/clear`→「阶段性稳定／处理完成」；`hp/damage`→「病情状态／病情进展」；`enemy`→不使用；`run`→「本次夜班」；`game over`→「本次夜班结束」；`revive`、`combo/streak`→不存在此机制。构建期扫描命中禁用词则构建失败。

### 12.3 死亡病例的教学化：M&M 框架

① 病例陈述（客观时间线，无评价）；② 关键决策点回放（含当时可见信息）；③ 可避免因素分析（知识/流程/资源/沟通/系统条件）；④ **不可避免因素说明**（明确指出疾病本身的严重程度）；⑤ 可推广的改进措施（个人 + 流程）；⑥ 知识点索引。

**第 4 项不得省略。** 规培医师最容易受到的伤害之一，是把所有坏结果都归因于自己。教学产品有责任示范正确的归因方式。

**需教师复核的严肃性事项**：死亡场景文案是否符合本院与本地文化语境；死亡告知流程与本院告知制度的一致性；是否需在入口增加心理支持资源指引；涉及治疗强度/治疗目标的呈现边界（规培医师权限）。**以上四项均需要临床教师与教务复核。**

**技术方案**：纯前端单页，`localStorage` 存档，无网络请求与用户追踪；**确定性生成**（单一种子的伪随机发生器，同种子必然复现同局，是教师复现与缺陷上报的基础）；数据文件分离 `NIGHT_CORES／NIGHT_SLOTS／NIGHT_RULES／NIGHT_TEXT／NIGHT_CODEX`，教师只改数据不改逻辑；构建期检查三项——禁用词扫描、剂量数字正则拦截（X6）、每个 core 必须有 `criticalActions／advisableHelpWindow／teacherApproved` 否则构建失败；移动端竖屏优先。

**内容量**：10—12 个 core、5 个模板、3 个 Boss、约 40 个事务/沟通节点、约 60 条图鉴、约 30 条线索。目标：连续 10 局不出现完全重复的病例组合。
