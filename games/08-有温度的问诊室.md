# 有温度的问诊室 · 剧情选择游戏设计文档

> 适用对象：内科专业基地规培第一年住院医师、临床实习阶段学生
> 载体：规培教学 Web App 分支叙事模块（单局 12–18 分钟，可复盘）
> 配套数据文件：`build/p51h_talk.js`（变量 `TALK_CASES`）
> 说明：本文所依据教材为人民卫生出版社《诊断学》（第 10 版）与《内科学》（第 10 版）。文中不标注页码，凡涉及剂量、分级标准、检查项目等具体数值处均标注「需要临床教师复核」，以最新版教材原文与现行指南为准。

## 一、游戏定位与学习目标

### 1.1 定位

《有温度的问诊室》是一款单人多分支对话模拟模块，填补真实接诊与标准化病人训练之间的空白：学员第一次独立面对患者之前，需要一个可以安全地犯错、且每次犯错都能被翻译成一句可操作的话的练习场。它要解决的问题是——规培学员的问诊失败多数不是因为不会问，而是在时间压力、患者情绪、家属插话与自身不确定性同时出现时注意力被挤走：问到一半被情绪带走，或一路追问把人问跑。本游戏把这种注意力争夺做成可量化的机制。三条设计边界：不考记忆性知识（剂量、分期、指南条款不作得分点，只在教学反馈中作背景）；不考操作技能（查体手法、装置演示另行接入视频模块）；只考一件事——能否同时拿到该拿的信息、守住该守的关系。

### 1.2 五个学习目标与可观测行为

| 目标 | 定义 | 游戏内可判定的动作 |
| --- | --- | --- |
| L1 病史采集完整性 | 按症状框架与系统回顾拿全诊断所需信息 | `keyInfo` 命中率；是否使用开放—收敛序列；是否对模糊表述做量化 |
| L2 危险信号识别 | 发现并正确处理报警症状，不「正常化」 | 是否对 `danger` 条目追问、复述或解释；是否出现正常化类负面行为 |
| L3 患者理解度 | 确认患者真的听懂，而非医生讲完了 | 是否使用回授法；是否条目化交代；是否询问执行障碍 |
| L4 信任建立 | 让患者愿意说出真实顾虑与真实行为 | 累计 `trust` 分；隐藏顾虑是否被成功引出 |
| L5 共同决策质量 | 在专业建议与患者偏好之间形成可执行共识 | 是否给出≥2 个可比选方案；是否确认偏好；是否约定时间节点与反馈方式 |

五个目标不是并列的加分项，而是两条主线在五个切面上的投影：L1、L2 属信息维度，L3、L4 属关系维度，L5 兼属两者——既要求方案内容专业，又要求方案被患者认可。这条结构直接决定了第三章的双轨评分制。

### 1.3 一局的结构

进入（患者档案卡，不给隐藏顾虑）→ 主对话（每节点 3–4 选项，选中即弹 `fb`，不中断流程但记入复盘）→ 结局（三分支定性总评）→ 复盘（五维雷达图 + 逐条「你说了什么—为什么更好/更差」+ 未命中清单；默认只展开错误项）。

## 二、对话选项类型体系

游戏共设 6 种正向类型 + 1 种负面行为类型，对应 `ty` 字段取值：`开放式提问`、`封闭式确认`、`澄清`、`共情回应`、`解释风险`、`共同决策`、`负面行为`。每个选项携带 `info`（0–2）、`trust`（−2 至 2）、`fb`（教学反馈）。

**类型的价值不在于本身好坏，而在于出现时机。** 同一句共情，在患者刚吐露恐惧时价值极高，在他描述症状细节时就是打断。

### 2.1 开放式提问

**定义**：不预设答案、让患者用自己的话叙述，句式如「怎么个疼法」「能跟我说说……吗」。

**适用时机**：① 节点开场，话题切换时先开放后收敛；② 患者主动给出新话题（体重、家人、费用）时顺势展开；③ 探索心理社会维度时几乎是唯一有效工具。

**评分逻辑**：`info` 1–2，`trust` 1–2。给信任分，是因为它传递了「你的叙述有价值」的信号。t1 的 n1 中「您说的老毛病，具体是怎么个疼法」与「您之前吃的什么药、吃了多久、效果怎么样」同为 info 2 / trust 1，但后者额外完成用药史采集，复盘中标注为更优。

**常见误区**：把它当万能好选项反复使用导致发散；**只开不收**——问完后未对回答做量化，复盘会标注「本节点有开放无收敛」。

### 2.2 封闭式确认

**定义**：用于量化、定位、核查的问题，答案是次数、天数、部位或是否。

**适用时机**：① 开放式提问之后立即跟进；② 危险信号必须闭合时（黑便问天数与性状、胸痛问放射与出汗）；③ 核查执行条件（陪护、过敏、麻醉史）。

**评分逻辑**：`info` 多为 2，`trust` 多为 1。信任分偏低不是不重要，而是它不承担关系功能。t1 的 n4「黑便一共几天？有没有头晕心慌、站起来眼前发黑」是本病例分值最高的信息动作之一。

**常见误区**：连续使用造成审讯感，尤以危险因素连珠炮式追问为甚；用封闭式提问过早关闭话题（患者刚说半句即被截断）则归入负面行为。

### 2.3 澄清

**定义**：不新增问题，而是对患者已说过的话做精确化。三类：词义澄清（「您说的消炎药是指抗生素还是平喘药」）、时间澄清（「半个多小时那种是一直疼还是时轻时重」）、意图澄清（「您是担心查出问题就没选择余地了吗」）。

**适用时机**：① 患者使用多义词或民间说法；② 同一症状出现两种模式需拆分评估；③ 回应重大顾虑前的复述验证。



**评分逻辑**：`info` 1–2，`trust` 1–2。**澄清是性价比最高的类型**，同时产出信息与信任，因为它证明医生在逐字听。t2 的 m4「您说的断不了，是担心像安眠药那样上瘾，还是担心要长期用」把长期用药与成瘾拆开，是病例转折点。

**常见误区**：把它做成诱导性提问（患者毫无线索时问「您是不是担心花钱」），属负面行为。


### 2.4 共情回应

**定义**：识别并命名患者的情绪或处境，不加判断、不急着解决，句式如「听起来您最怕的不是……而是……」。

**适用时机**：① 患者暴露情绪的当下（停顿、哭泣、说出恐惧、被家属否定后）；② 坏消息或高风险信息之前；③ 被误解或对抗时先接后转。

**评分逻辑**：**这是唯一信息分可以为 0 的正向类型**。t1 的 n8「又担心花钱又担心受罪，两头为难确实让人很难下决心」是 info 0 / trust 2。这个设计是刻意的：**共情不是信息的替代品**。一局中共情占比过高，信任分很高而信息分很低，最终落入「一般」结局。

**常见误区**：假共情（见 4.5）；共情后立即转移话题，使共情显得像话术。正确序列是：命名情绪 → 停顿 → 追问或解释。


### 2.5 解释风险

**定义**：把医学判断翻译成患者可理解的因果与代价，含三层——为什么需要做（与个人情况绑定）、不做的代价、做了会怎样。


**适用时机**：① 需要患者接受不舒服或昂贵的检查/治疗前；② 患者基于错误认知拒绝时；③ 交代随访与报警症状时。


**评分逻辑**：`info` 1–2，`trust` 1–2。给信息分，是因为好的风险解释必然包含对患者具体情况的复述，这本身就是信息闭环的证明。t1 的 n8「您有 50 岁以后新发症状、体重下降、黑便这几点」info 2 / trust 2，为全病例最高。

**常见误区**：只讲概率不讲个人（「胃镜很安全」）；只讲收益不讲代价，导致预期落空；以术语完成解释（见 4.3）。

### 2.6 共同决策

**定义**：在给出专业建议的前提下把选择权部分交还患者，含四个可判定动作：提供≥2 个可比选方案、说明利弊、询问偏好、约定时间节点与反馈方式。


**适用时机**：① 存在多个合理选项时；② 依从性是主要矛盾时（慢病长期用药、戒烟）——此时没有共识的方案等于没有方案；③ 收尾时把口头共识固化为可执行计划。


**评分逻辑**：`info` 1–2、`trust` 1–2，并直接影响 L5。t2 的 m6「咱们先定三个月……三个月后一起评估」是范式——它把无法接受的「终身用药」替换为「三个月的试验」。

**常见误区**：伪共同决策——「您自己选吧，两种都一样」。看似尊重，实为把患者推入信息不对等的选择，判为负面行为；真正的共同决策必须先给专业判断，再给选择空间。

### 2.7 负面行为

`ty` 为 `负面行为` 的选项约占四分之一，是刻意设计的密度：信息分与信任分至少一个为 0 或负，且 `fb` 长于正向选项——错误更需要讲透。详见第四章。

## 三、核心规则：不能仅靠选择「最温柔的话」得高分

### 3.1 规则的由来

初版原型测试中有一个稳定的失败模式：**学员策略性地选择最体贴、最不冒犯的选项，满意度一路走高，病史采集完成率却不足一半。** 他们并非不知道要问什么，而是在「温柔 = 正确」的直觉下系统性地回避了可能让患者不舒服的追问——体重下降、黑便、吸烟、家族史。由此确立核心规则：**温柔不是加分项，温柔是入场券。**

### 3.2 评分双轨制

每局结算两个互相独立、不可通兑的分数。

**轨道 A · 信息维度（100 分）**：关键病史命中率 50（`keyInfo` 命中数/总数，相关但不充分者记 0.5）；危险信号识别 30（每个 `danger` 三档：未提及 0 / 追问到 0.6 / 追问并解释或处置 1.0）；信息采集结构 20（开放—收闭序列完整性、模糊表述量化率）。

**轨道 B · 关系维度（100 分）**：信任累计 40（`trust` 归一，同类型连续使用递减，连续 3 次共情后折算 0.6）；顾虑引出 30（隐藏顾虑是否被说出及被回应）；理解度核实 30（回授法、条目化交代、障碍询问）。

**关键约束：两轨不可通兑。** 信息 95 分、关系 40 分，结果是「一般」而非「优秀」。该规则通过阈值门实现，而非加权求和——加权会让高分轨掩盖低分轨。

### 3.3 三条「看起来不错但会失败」的路径

**路径一 · 一路温柔。** 全程共情与顺从，trust 接近满分，却漏掉黑便鉴别与体重量化。入口是 t1 n1 的选项二（trust +1，info 0），其 `fb` 直书「属于典型的『服务态度好但医疗质量差』」。一路如此，患者满意离开而出血被放过，结局**不合格**。

**路径二 · 一路追问。** `keyInfo` 全中，却在患者说出「我要是也这样，这家怎么办」时继续追问症状。信息高分、关系低于阈值，结局文本写：「她同意做检查，但是被动同意……失访的可能性明显升高。」结局**一般**。

**路径三 · 正确但生硬。** 医学判断全对，表达却是单向指令——「必须先做胃镜」「所有止痛药都停，忍着」。`info` 不低，但 `trust` 为 −1 至 −2，同样落入**一般**，复盘标注「医嘱正确但不具备可执行性」。

### 3.4 阈值门规则

```
优秀：  info >= 80  且  trust >= 70  且  无严重负面行为
一般：  未同时满足上述条件，但 info >= 60  且  trust >= 50
不合格：info < 60  或  trust < 50  或  触发任一严重负面行为
```

**严重负面行为**（一票否决，直接进不合格结局）每例设 1–2 个，均为可能造成不可逆后果的失误：

| 病例 | 选项 | 失误性质 |
| --- | --- | --- |
| t1 | 「吃猪血确实会黑便，没事」 | 放弃上消化道出血的鉴别 |
| t1 | 「费用您别管，检查最重要，先做了再说」 | 未解释即强推，信任崩塌 |
| t2 | 「觉得没用就停了吧，反正您也不想吸」 | 在患者最需指导时放弃专业立场 |
| t3 | 「年轻女性吃避孕药问题不大，您父亲那是他自己的事」 | 同时忽视家族史与可逆危险因素 |
| t3 | 「都正常就别想了，回家好好休息」 | 把阴性结果当作终点 |

### 3.5 一个反直觉设计：正向选项也可以只有 0 分

t1 n8 的「又担心花钱又担心受罪」与 t2 m1 的「花不少钱买了药却没感觉到效果」均为 info 0 / trust 2：不扣分，但也不推进诊断。这样设计是为了让学员看见——关系是成本，需要被支付。

## 四、负面行为设计

五类核心负面行为，每类给出定义、机制与游戏内后果。所有 `fb` 遵循同一结构：**这句话做了什么 → 患者会怎么理解 → 本来可以怎么说**；替代示范不可省略，否则学员只知道错了不知道怎么改。

### 4.1 过早打断

**表现**：患者叙述未完成时插入提问、转移话题，或替患者把话说完。

**机制**：患者主诉叙述在被打断前的时长很短（**具体数据需要临床教师复核**），而「最后一句话」往往才是真正来就诊的原因。打断的直接后果不是不礼貌，而是丢信息。

**游戏内实现**：t1 n2 的「这就是典型的十二指肠溃疡，不用问了」info 0 / trust −1，同时犯了两个错——打断叙述，且在尚未采集报警症状时下诊断。

### 4.2 诱导性提问

**表现**：把答案放进问题里，或提出患者毫无线索的假设。

**机制**：它获取的不是信息，而是患者对医生期待的顺从——权力不对等的诊室里患者倾向于回答「是」，于是制造出「已经问过了」的虚假完成感。

**游戏内实现**：本模块刻意未把它做成显性选项，而是隐藏在「澄清」的错误使用中——t1 n7 若在患者尚未给出经济线索时追问费用，复盘会标记「澄清过早」。

### 4.3 术语堆砌

**表现**：用未经翻译的术语完成解释与交代——「需要排除上消化道恶性病变」「这是长期维持治疗」「植物神经功能紊乱」。

**机制**：后果不是患者听不懂，而是患者不好意思说听不懂。于是理解度归零，而医生以为已交代完毕。**这是最容易发生在优秀学员身上的负面行为。**

**游戏内实现**：t1 n13「注意事项单子上都写着，回去看就行」——以书面材料替代口头确认，理解度归零，进入「一般」结局；t3 j2「基本就是植物神经紊乱」——以术语完成归因，伴随误判风险。反馈给出翻译示范。

### 4.4 忽视顾虑

**表现**：患者明确表达担忧后不回应即推进自身议程——「费用您别管，检查最重要」「您先别问那么远，做了再说」。

**机制**：被忽视的顾虑不会消失，只会转入地下——患者不再提问，改为不履行（不预约检查、自行停药）。表面沟通顺畅，实际共识为零。

**游戏内实现**：t1 n8 选项四与 n9 选项四对应两种形态——以「为你好」压过顾虑（trust −1，不合格）与直接拒绝回答（trust −2，一般）。

### 4.5 假共情

**表现**：形式上安慰，内容上否认或回避情绪与处境：「您别想那么多，现在的医学很发达」「放心，您肯定没有病，就是压力大」「慢阻肺就这样，年纪大了都喘」。

**机制**：假共情比冷漠更有害，因为它关闭了患者刚刚打开的自我暴露通道——患者收到的信号是「这个话题到此为止」，于是把更深的顾虑收回去；它常伴随虚假保证，一旦结果不如预期，信任损失是双倍的。

**游戏内实现**：t1 n7「您别想那么多，现在的医学很发达」（trust −2）；t2 m3「慢阻肺就这样，年纪大了都喘」——治疗性虚无主义（trust −2）；t3 j4「放心，您肯定没有病，就是压力大」——以保证代替评估（trust −2）。

## 五、患者多样性设计

### 5.1 四个维度

| 维度 | 设计作用 | 三例中的分布 |
| --- | --- | --- |
| 文化背景 | 影响疾病解释模型与对检查、药物的态度 | t1 母亲因胃癌去世形成的疾病观；t3 对心理标签的顾虑 |
| 健康素养 | 决定术语翻译的强度与回授法的必要性 | t1 依赖邻居经验；t2 依赖工友口耳相传；t3 易受网络信息干扰 |
| 家庭关系 | 影响决策者与信息来源，也影响顾虑的表达 | t1 女儿代述推动就医；t2 老伴反对；t3 独居、顾虑母亲看法 |
| 治疗偏好 | 影响共同决策的方案设计与排序 | t1 怕受罪怕花钱；t2 信输液；t3 抗拒心理科转诊 |

四维度是叠加而非对应关系：t1 的陈桂芳同时健康素养较低、家庭决策权分散、对侵入性检查高度抗拒。

### 5.2 禁止歧视性刻板印象的五条硬性规则

1. **不作群体性归因**。性格、依从性、理解能力上的特征必须落在这一个人物身上（她的母亲死于胃癌、他听工友说过激素副作用），而非她所属的群体。
2. **不因年龄贬损**。老年患者的保守不构成「固执」，年轻患者的焦虑不构成「矫情」。t2 对激素的恐惧有具体信息源；t3 的年轻不构成降低排查力度的理由。
3. **不因性别与职业标签化**。不出现「女性更易情绪化」「某职业更易隐瞒病史」一类设定或反馈。t3 中「年轻女性胸痛常被归因为焦虑」是作为**需要被纠正的偏见**出现，而非设定。
4. **经济状况中性呈现**。经济困难只作为沟通与执行障碍呈现（影响方案选择与依从性，需医生主动询问），不作人格描写、不作评价患者的标准。t1 中「刚给儿子付了首付」是真实的决策约束，游戏要求学员正视它，而非评判它。
5. **地域与教育背景不作笑点**。不使用方言梗、口音梗、文化程度梗。

### 5.3 新增病例写作检查清单

隐藏顾虑是否由个人经历支撑？患者的「不依从」是否有可理解且可被回应的理由？是否存在以性别、年龄、职业、地域、经济状况为依据的贬损或标签化描写？家属是否是在推动或阻碍而非代替患者表达？结局文本是否避免了单向胜利叙事？

## 六、三位患者设定

### 6.1 病例一：陈桂芳（t1 · 上消化道症状与胃癌顾虑）

**人物背景**：女，58 岁，小学教师，农村户籍。近 3 个月反复上腹隐痛、反酸，自行服胃药间断缓解。女儿陪同，进门即要求「开点之前那个药就行」。

**隐藏顾虑**（双层，需分两次引出）：① 结果恐惧——母亲死于胃癌，确诊到去世不到一年，她怕的不是胃镜而是「听到那个结果」；② 负担恐惧——刚给儿子付了首付，手头紧，怕查出重病拖累家里。

**关键病史**：疼痛与进食关系及夜间痛（空腹加重、进食缓解、夜间痛醒，**该节律与溃疡类型的对应关系需临床教师复核**）；体重下降幅度（患者只说「瘦了点」，须主动量化）；黑便或呕血史（自行归因于吃猪血）；NSAIDs 服用史（长期服「去痛片」，成分与剂量不明）；胃癌家族史（母亲，需具体化到发病年龄）；报警症状系统筛查。

**危险信号**：体重下降超过 5 kg；黑便提示上消化道出血；50 岁以上新发消化不良症状需警惕恶性病变。

**沟通难点**：① 开场即被设定议程——患者带着「开药」目标前来，任何偏离都被体验为拖延，学员须在顺从（丢信息）与强硬（丢关系）间找到第三条路：先承认其既往经验再展开采集；② 报警症状的自我合理化——患者为黑便提供了现成解释且并非完全不可能，不能简单否定，须追问性状、天数与循环系统伴随症状；③ 检查沟通与双重恐惧交织——单靠解释必要性不够，须把两层顾虑都接住，并把方案切成可决定的小块。

**教学要点**：消化性溃疡与胃癌症状重叠，「老毛病」的自我诊断不能替代本次评估；NSAIDs 相关胃肠损伤是可逆危险因素，停药须配合替代方案；报警症状不能靠患者主动提供；「顺从式服务」是最隐蔽的失败模式。

**节点结构**：14 个对话节点（n1–n14）+ 3 个结局节点。

### 6.2 病例二：李国栋（t2 · 慢阻肺患者不愿长期吸入激素）

**人物背景**：男，68 岁，退休建筑工人，吸烟 40 包年。确诊慢阻肺 2 年，规律开药但自行停用吸入剂，近 1 年两次因急性加重住院。老伴陪同，反复要求输液。

**隐藏顾虑**：① 认定吸入剂里的激素会「上瘾、发胖、把骨头吃坏」，信息来自工友老张，属社会性信息源因而更顽固；② 认为「吸了没感觉就等于没用」，把即时缓解当作药效唯一标准；③ 认为「抽了四十年烟，戒了也没用」，是深层无力感而非认知错误。

**关键病史**：呼吸困难程度与活动耐量；急性加重次数与住院史；吸入装置使用技术与实际依从性；吸烟量与戒烟意愿；对吸入激素的具体误解；合并用药与自行购药情况。

**危险信号**：一年两次急性加重住院提示高风险；活动后气促进行性加重需排除肺心病与心力衰竭；长期重度吸烟者新发体重下降需排查肺癌。

**沟通难点**：① 诉求与病情错位——患者要输液，真正治疗是长期吸入。直接反驳会被理解为「医生不给我治」，顺从则强化错误认知；正确入口是核查吸入技术，它把「药没效」的争论转化为可共同检查的事实问题；② 恐惧的具体性——「激素」对患者不是药物类别，而是发胖、骨头坏、断不了三个画面，笼统说「很安全」无效；③ 评价标准冲突——m6 通过重新定义「有效」（看加重次数与活动耐力）来解决；④ 老伴参与经济决策且持反对意见，忽略她等于埋下停药的种子。

**教学要点**：依从性评估第一步永远是核查技术而非判断疗效；急性加重频率是决定治疗强度的核心依据（**分级与治疗推荐需临床教师复核**）；长期控制药物与缓解药物的功能区分是教育核心；戒烟获益不受年龄与累积暴露量影响（**获益数据需临床教师复核**）；把「终身用药」重构为「有期限的试验」。

**节点结构**：6 个对话节点（m1–m6）+ 3 个结局节点。

### 6.3 病例三：林悦（t3 · 年轻女性胸痛与焦虑）

**人物背景**：女，26 岁，互联网公司运营，独居。近 2 个月反复胸痛、心悸、憋气，多于加班后或入睡前出现。两次急诊查心电图与心肌损伤标志物均未见异常，同事多次说她「就是太焦虑」。

**隐藏顾虑**：① 怕被贴标签——最担心的不是查出病，而是被判定为「精神上有问题」，怕影响工作评价与母亲的看法；② 怕真有病——父亲 45 岁急性心肌梗死并植入支架；③ 怕被否认——两次急诊「都没事」但她确实难受。

**关键病史**：胸痛的部位、性质、诱因、持续时间与缓解方式；心悸发作特点；伴随的呼吸困难、晕厥、出汗；心血管危险因素（早发冠心病家族史、吸烟、口服避孕药）；情绪与躯体症状的时间关联；既往惊恐发作或焦虑诊疗史。

**危险信号**：早发冠心病家族史叠加吸烟与口服避孕药的血栓风险（**风险量化需临床教师复核**）；活动诱发的胸痛、晕厥或近乎晕厥；单侧下肢肿痛伴呼吸困难需警惕肺栓塞。

**沟通难点**：① 「阴性结果 = 没事」的推理陷阱是本病例主要教学靶点——正常心电图与心肌损伤标志物不能排除所有危险，更不能替代问诊，j1 选项四是两个一票否决项之一；② 危险因素的隐蔽性——三条危险因素都需主动询问才会暴露，以年龄为捷径做判断会全部漏掉，j3 选项四是第二个一票否决项；③ 双轨并行的表达难度——只讲排查她会觉得被当成疑病症，只讲情绪她会觉得又被打发，j4 的三个正向选项分别用共情、澄清、解释风险完成这件事；④ 阴性结果之后路径缺失——j6 只交代症状日记不足以回应「都正常怎么办」。

**教学要点**：胸痛五要素框架不因年龄而简化；早发冠心病家族史需具体化到亲属与发病年龄；口服避孕药与吸烟叠加的血栓风险常被低估（**需临床教师复核**）；「器质性」与「心理性」不是互斥选项；检查应按风险与侵入性排序，而非「全套做一遍」。

**节点结构**：6 个对话节点（j1–j6）+ 3 个结局节点。

## 七、结局评价体系

### 7.1 五维评分

| 维度 | 数据来源 | 主要失分点 |
| --- | --- | --- |
| 病史完整性 | `keyInfo` 命中率 + 采集结构分 | 只选共情不追问；模糊表述未量化 |
| 危险信号识别 | `danger` 三档判定 | 正常化（把报警症状解释为良性） |
| 患者理解度 | 回授法 + 条目化交代 + 障碍询问 | 术语堆砌；以书面材料替代口头确认 |
| 信任 | `trust` 累计（含递减系数）+ 顾虑引出 | 假共情、忽视顾虑、单向指令 |
| 决策质量 | 方案可比选性 + 偏好确认 + 时间节点约定 | 伪共同决策；未约定随访 |

五维以雷达图呈现，默认提示「最弱的一维是什么」——它往往就是本局失败的原因。

### 7.2 三类结局分支

**结局 A · 优秀**（信息 ≥ 80 且 关系 ≥ 70 且 无严重负面行为）：文本描述患者**主动参与**的结果。三例共同特征是——患者提供了医生没有问到的新信息，这是信任建立最可靠的指标：t1「这是我第一次觉得自己被听进去了」，t2「那我们就先试三个月」，t3「原来可以同时是两件事」。

**结局 B · 一般**（信息 ≥ 60 且 关系 ≥ 50 但未同时达优秀阈值）：最常见也最值得教学的结局，因为失败是局部的、可定位的。三例文本均点明缺口：t1 是「被动同意」，t2 是「心里仍认定这药大概没用」，t3 是「对结果的解读仍是一片茫然」。

**结局 C · 不合格**（信息 < 60 或 关系 < 50 或 触发严重负面行为）：文本均包含两句话——临床上漏掉了什么、关系上损失了什么，并给出重新进入的起点提示。

### 7.3 结局与节点路径的关系

结局节点通过 `next` 直接跳转：严重负面行为跳入 `e*_bad`，次优选项跳入 `e*_mid`，优质选项汇入 `e*_good`。这是数据结构上的简化；**教学上仍建议 App 层在结算时同时展示双轨分**，因为同一结局可能来自不同的失败路径。

### 7.4 复盘报告结构

① 定性结论（结局类型 + 一句话归因）；② 未命中清单（未采集的 `keyInfo`、未识别的 `danger`）；③ 错误回放（`trust` 为负的选项，附 `fb` 与替代示范）；④ 类型分布（六类选项比例与推荐值对照：开放式 25%、封闭式 30%、澄清 10%、共情 15%、解释风险 10%、共同决策 10%，**该比例为本模块经验值，需临床教师复核**）；⑤ 一句话带走（最高优先级改进项）。

- [ ] 阴性检查结果的临床意义是否准确？家族史与危险因素的关联强度是否被夸大？

**B. 沟通教学有效性**
- [ ] 每个节点的选项是否类型不同，而非同一类型的不同措辞？
- [ ] 正向选项的 `fb` 是否说明了「为什么好」，而非仅作肯定？
- [ ] 负面行为的 `fb` 是否包含替代示范？次优选项是否被合理赋分？
- [ ] 共情选项 info 为 0 时，`fb` 是否提示「下一步必须回到信息采集」？
- [ ] 结局文本是否说明了临床上漏掉了什么，而非只评价态度？

**C. 价值与安全**
- [ ] 是否逐条通过 5.2 的五条禁止歧视规则？
- [ ] 经济状况是否仅作为执行障碍中性呈现？
- [ ] 是否出现「患者终于被说服」一类单向胜利叙事？
- [ ] 是否出现对某一人群（老年人、女性、低健康素养者、特定职业）的概括性负面描述？
- [ ] 家属角色是否尊重患者本人的主体性？
- [ ] 负面选项中若出现现实中不可接受的表达，其 `fb` 是否足够明确以防止模仿？

**D. 技术实现**
- [ ] `p51h_talk.js` 是否通过 `node --check`？
- [ ] 非结局节点的 `opts` 是否为 3–4 项？结局节点的 `opts` 是否为空数组？
- [ ] 每个 `next` 是否指向本病例内已定义的节点 id？是否存在不可达节点？
- [ ] `info` 是否落在 0–2、`trust` 是否落在 −2 至 2？
- [ ] 字符串内是否使用「」而非英文双引号？
- [ ] 阈值门是否在 App 层实现，且双轨分不可通兑？

### 9.3 知识点的教学转化原则

每个知识点遵循同一条转化规则：**不直接考「知不知道」，而是考「会不会在对话中用出来」。** 例如「NSAIDs 相关胃十二指肠损伤」，游戏中不设选择题问机制，而是把「追问去痛片的成分与累积剂量」设为 info 2 的选项，并在 `fb` 中说明它为何重要——选不出这个选项，就说明该知识点尚未转化为行为。其副产品是：**游戏天然地区分了「背得出」与「做得到」**。

## 附录：数据文件字段说明

`build/p51h_talk.js` 导出全局变量 `TALK_CASES`。病例层字段：`id`、`name`、`age`、`bg`、`hidden`（隐藏顾虑，界面不展示，需特定选项引出）、`keyInfo`（病史完整性评分依据）、`danger`（危险信号识别评分依据）。节点层字段：`id`、`say`、`opts`。选项层字段：`t`（文字）、`ty`（类型）、`info`（0–2）、`trust`（−2 至 2）、`fb`（教学反馈，选中即展示）、`next`（下一节点 id）；`opts` 为空数组者即为结局节点。

当前数据规模：3 个病例；t1 含 14 个对话节点 + 3 个结局节点，t2、t3 各 6 个对话节点 + 3 个结局节点；非结局节点选项数均为 3–4 项；所有 `next` 均指向本病例内已定义节点；文件通过 `node --check` 校验。
