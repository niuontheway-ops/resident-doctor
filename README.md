# 壶兰呼吸 · 规培版（上线材料清单）

## 一、必须上传的文件（缺一不可）

| 文件/目录 | 内容 | 体积 | 为什么必须 |
|---|---|---|---|
| `index.html` | 自动跳转入口页（GitHub Pages 默认只认 index.html） | 1KB | 没有它访问根路径会 404 |
| `壶兰呼吸-规培版.html` | 应用主文件（1300KB，全部功能与数据都在里面） | 1.3MB | 应用本体 |
| `audio/` | 18 条真实听诊录音（mp3） | 2.5MB | 听诊模块播放依赖相对路径 `audio/*.mp3` |
| `img/` | 67 张真实影像（胸片/CT/心电图/听诊部位图） | 12MB | 影像判读与听诊部位图依赖 `img/*.jpg` |

⚠️ 三者必须放在**同一层目录**，且 `audio/` `img/` 不能改名，否则听诊没声音、影像不显示。

## 二、建议一起上传的（可选但推荐）

- `build/` —— 58 个源码分片 + 采集脚本，便于后续二次开发（不上传也不影响运行）
- `README.md` —— 项目说明
- `.nojekyll` —— 空文件，告诉 GitHub Pages 不要走 Jekyll 处理（避免中文文件名被过滤）

## 三、部署步骤

1. 新建仓库（例如 `human-breath`），可见性 Public；
2. 上传上述 4 项（保持目录结构）；
3. `Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main、Folder: /(root) → Save`；
4. 等 1–3 分钟，访问 `https://<你的用户名>.github.io/human-breath/` 即自动跳进应用。

## 四、关于版权

- 应用内所有文字（讲义、考点、题库、值班宝典、法规解读）均为原创整理，可公开；
- 教材侧仅使用《内科学》《诊断学》的**目录结构与页码**（事实信息），不含教材正文或扫描图；
- 音频与影像全部来自 CC0 / CC BY / CC BY-SA / PD / ODC-BY 授权来源，每条在 App 内都有作者、许可与原始出处链接。

## 五、本地使用

直接双击 `壶兰呼吸-规培版.html`（Chrome / Edge），需保证 `audio/` 与 `img/` 与其同目录。
